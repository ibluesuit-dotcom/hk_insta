# 한국경제TV 뉴스 카드 스튜디오

원문을 확인하고 문안을 다듬어 **표지 1장 + 본문 1~8장**을 만드는 단일 사용자 로컬 웹앱입니다. 1080×1350 PNG, 순서가 고정된 ZIP, 캡션 및 대체 텍스트를 다운로드합니다. 공용 계정 로그인 후 바로 스튜디오가 열립니다. 게시·외부 계정 연동·AI 이미지 생성은 없습니다.

## 실행

Node.js 22.16 이상(개발 검증: 24.13.1), npm, Chromium 실행이 가능한 macOS/Linux 환경이 필요합니다.

```sh
npm ci
npx playwright install chromium
npm run build
npm start
```

앱: **http://127.0.0.1:4310**. 개발 모드는 `npm run dev`입니다. 서버는 loopback 주소에만 바인딩합니다. `PORT`로 포트를 변경할 수 있습니다.

### OpenAI 설정

Responses API의 **`gpt-6-astra` 고정** 모델과 Structured Outputs를 사용합니다. 환경 변수 `OPENAI_API_KEY`가 우선이며, 없으면 사용자가 지정한 외부 `.env` 파일(`OPENAI_ENV_FILE`)에서 `OPENAI_API_KEY`만 읽습니다. 키는 서버 메모리에만 존재하며 파일을 수정·복사하거나 클라이언트에 전달하지 않습니다. 외부 파일 경로는 `OPENAI_ENV_FILE`로 변경할 수 있습니다. 새 키 입력 UI는 없습니다.

**본문 문안 생성의 실제 API 품질·비용은 별도 검증이 필요합니다.** 제목의 의미 단위 줄바꿈은 기존 계정의 실제 API 응답과 카드 렌더를 확인했습니다. 계정에 모델 접근 권한이 없으면 AI 오류가 표시됩니다.

무료 기능 점검용 모의 모드:

```sh
npm run dev:mock
```

**http://127.0.0.1:4311**, 저장소 `data/mock`. 노란 테스트 배너가 항상 표시되며 생성 결과는 실제 기사 요약이 아닌 고정 형식 예시입니다. `MOCK_DELAY=800`으로 지연 응답 시험도 가능합니다. 일반 실행은 모의 모드를 사용하지 않습니다.

## 제작 흐름

1. 새 작업에서 URL, 붙여넣기 또는 TXT·MD·DOCX·PDF(파일별 10MB)를 입력합니다. 파일별 성공/실패가 표시되며 통합 원문, 제목, 원래 부제, 발행 시점을 확인하고 수정합니다. 파일별 수정 이후에는 **통합 원문 갱신**을 눌러 반영합니다. 통합 원문은 최대 60,000자입니다.
2. 별도 제작 방향과 본문 장수를 선택하고 적용합니다. 타이핑, 장수 변경, 사진·크롭 조절은 AI를 호출하지 않습니다. 새 방향 미반영 상태가 표시됩니다. 본문 장수 감소는 삭제할 문안·잠금을 알리는 확인 후 적용하며, 취소하면 그대로 유지됩니다. 편집 탭의 앞/뒤 이동은 페이지 문안·근거·강조·대체 텍스트와 잠금을 함께 이동합니다.
3. AI 출력의 페이지 역할과 원문 인용을 확인하고 제목·부제·페이지·검색어·캡션·대체 텍스트를 편집합니다. 해당 필드/페이지를 잠그거나 추가 방향을 넣어 부분 재생성합니다. 부분 호출은 해당 범위의 JSON Schema만 요청합니다.
4. JPG·PNG·WebP(25MB 이하, 디코딩 5천만 픽셀 이하) 사진을 파일 선택 또는 드래그앤드롭으로 첨부합니다. 4:5 크롭 화면에서 초점·확대를 조정하고 크레딧을 입력합니다. 서버 보관용 사진은 EXIF 방향을 반영하여 최대 4000×5000 JPEG로 저장합니다. 사용자 원본은 건드리지 않습니다.
5. 문안 승인과 완성 이미지 승인을 별도로 수행합니다. 전체 렌더 후 원본 또는 320/360/390px 휴대폰 목업으로 모든 장을 확인합니다. 목업의 계정명·프로필 사진은 표시용 설정이며, 이것만 바꾸면 문안·이미지 승인과 기존 렌더를 보존합니다.
6. ZIP과 개별 PNG를 다운로드합니다. ZIP은 `01-cover.png`, `02-body.png` … 순서이며 캡션·대체 텍스트·버전 manifest도 포함합니다. 텍스트는 승인 전에도 **초안 TXT**로 별도 다운로드할 수 있습니다.
7. 작업 보관함에서 제목 검색·상태 필터·재개·복제·이전 버전 복원을 사용할 수 있습니다. 복원이나 변경 이후에는 재검수가 필요합니다.

원문 인용이 원문에 존재하는지 검증하지만, JSON 형식이나 인용 일치가 사실 정확성을 보장하지 않습니다. **숫자·단위·시점·비교 기준·대상·조건·전망과 실적 구분은 사람이 검수해야 합니다.** 예시 이미지에 사용된 스위스 무역 수치와 모의 기사 수치는 형식 확인용입니다.

## 구성과 선택 이유

- **React + TypeScript + Vite**: 별도 계정이나 클라우드 없이 로컬 편집 화면 제공.
- **Express 서버 + JSON 파일 저장소**: 단일 사용자 규모에서 추가 DB 설치 없이 영구 보존. `data/projects/<id>.json`에 현재 상태와 전체 이전 버전을 저장하고 임시 파일→rename으로 교체합니다. 프로세스 내 mutation queue와 revision 비교로 동시 저장 충돌 및 오래된 AI·렌더 결과 적용을 막습니다. 같은 저장소를 쓰는 서버 프로세스는 **하나만** 실행하세요.
- **고정 HTML/CSS + Playwright Chromium**: 전달된 실물 디자인을 그대로 구현하고 같은 PNG를 목업·내보내기에 사용합니다. AI는 HTML/CSS나 좌표를 생성하지 않습니다.
- **로컬 Pretendard 1.3.9 variable WOFF2**: `public/fonts`에 실제 파일과 SIL OFL 라이선스를 포함합니다. 렌더에서 font-face 로딩을 확인하며 실패 시 폴백 출력을 허용하지 않습니다.
- **Responses API + Zod**: 엄격한 구조 출력과 서버 검증, 범위별 스키마, 정확한 원문 quote 포함 검증. 프롬프트·템플릿·폰트 버전과 호출 모델·usage를 버전별로 보존합니다.

핵심 파일: `src/main.tsx`(편집·보관함·목업), `server/index.ts`(로컬 API), `server/ai.ts`(프롬프트·스키마), `server/render.ts`(고정 템플릿·DOM 조판), `server/store.ts`(버전 저장), `server/extract.ts` 및 `isolated-extract.ts`(추출), `shared/model.ts`(데이터 모델).

### 디자인과 조판

표지 원본: `design_handoff_news_card_fullbleed/README.md`, `News Card 1a.dc.html`. 64px 외곽 여백, 32/18px 그룹 간격, 남색 그라데이션, 빨강 부제 태그, 흰 제목과 노란 강조, 사진·크레딧·도메인을 고정 재현합니다.

제목은 실제 Pretendard DOM 너비로 여러 줄바꿈 후보를 비교하고 숫자·단위 묶음(`37억 9천만`, `2조 5천억 원`)과 화폐명(`스위스 프랑`)을 보존하며 **88→80→72px** 순으로 최대 3줄을 검사합니다. 단어를 강제 분리하거나 생략하지 않으며 72px에서도 넘치면 수정 요청으로 종료합니다. 수동 줄바꿈은 원래 문구를 유지해야 합니다. 부제는 공백 포함 20자 검사와 실제 pixel 너비 검사 모두 수행합니다. 표지의 노란 강조는 선택한 시작 줄(0-based `highlightFrom`)부터 마지막 줄까지 적용하며 `null`은 모두 흰색입니다. 기존 부분 강조 문자열은 데이터에 보존하지만 표지 렌더는 시작 줄 설정을 사용합니다. 본문 부분 문자열 강조는 유지합니다.

본문은 남색 배경·흰 본문·노란 강조, 기본 60px, 수동 선택 하한 54px입니다. 100~120자와 7~9행을 편집 목표로 삼고, 글자 수를 표시하며 실제 높이·가로 넘침을 검사합니다. 자동 축소·자동 생략은 하지 않습니다. 본문 하단 번호는 `본문 n/N`으로 표기하여 캐러셀 전체 순번과 구분합니다.

### 저장 및 오류 복구

`DATA_DIR` 기본값은 `data`입니다. 전체 디렉터리를 복사하면 작업·사진·렌더를 함께 백업할 수 있습니다. 원문, 파일별 추출 결과, 제작 방향, 문안·근거, 사진, 초점·확대·크레딧, 잠금, 수동 줄바꿈, 본문 폰트, 목업 설정, 버전 정보를 저장합니다. 작성 중에는 650ms 후 서버 자동 저장하며 실패 상태를 표시하고 다시 저장할 수 있습니다. AI·렌더·사진/문서 처리 및 저장 작업 중에는 모든 편집 입력·장수·방향·크롭·프로필 변경을 잠시 비활성화합니다. 자동 저장과 장시간 작업을 직렬화하며 작업을 시작하기 전에 미저장 편집을 저장합니다. 창을 닫기 전 저장 완료를 확인하세요.

오류는 `AI`, `EXTRACTION`, `FONT`, `IMAGE`, `RENDER`, `CONFLICT/STALE`로 구분합니다. 사진 오류는 다시 첨부, 폰트 오류는 배포 파일 복구, 넘침은 문구 수정 후 재렌더, AI 오류는 설정 확인 후 재생성합니다. 다른 창과 저장 충돌이 나면 자동 재저장을 중단하고 이 창의 미저장 내용을 유지합니다. 오류 배너의 **로컬 초안 보관**으로 JSON을 내려받고, **최신 작업 열기**의 확인 후 서버 작업과 비교하세요. 로컬 JSON 자동 가져오기는 제공하지 않습니다. 오류 시 기존 결과와 원문은 삭제되지 않습니다.

URL은 공개 HTTP/HTTPS만 허용하며 DNS 결과의 사설·loopback·link-local·IPv4-mapped 주소를 차단하고 검증한 IP에 요청을 고정합니다. 리다이렉트마다 재검사하며 2MB/요청 15초/3회 redirect 제한을 둡니다. HTML 스크립트는 실행하지 않고 텍스트를 추출합니다. 파일은 확장자·내용을 확인하고 DOCX 압축 해제 25MB, PDF 100페이지 제한을 둡니다. 별도 추출 프로세스는 15초/Node heap 256MB 제한을 갖습니다. 템플릿의 모든 사용자 문자열은 HTML escape합니다.

## 알려진 제한

- 스캔·이미지 PDF의 OCR은 제공하지 않습니다. 암호화·손상 PDF, 동적 렌더/유료벽 기사, 일부 사이트 문자 인코딩은 직접 텍스트 붙여넣기로 복구합니다. URL 메타데이터는 없는 값을 추측하지 않습니다.
- 실물 휴대폰과 편집자의 30개 기사 의미 검수, 실제 OpenAI 응답 품질 평가는 미실행입니다. 목업은 Chromium의 표시 폭 시험입니다.
- 단일 프로세스 로컬용 저장소이며 여러 서버의 동시 쓰기·다중 사용자는 지원하지 않습니다. 버전과 렌더는 자동 삭제하지 않으므로 장기 사용 시 백업·디스크 관리가 필요합니다.
- 버전 스냅샷 압축/상한·보관함 요약 파일 분리와 Chromium 프로세스 재사용은 후속 최적화입니다. 현재 버전을 자동 삭제하지 않으며 렌더 요청마다 Chromium을 기동합니다.
- 현재 카드만 렌더는 빠른 확인용입니다. 전체 이미지 승인·다운로드를 위해서는 현재 버전 전체 렌더를 수행해야 합니다.
- 생성은 페이지 역할/근거를 앞에 두는 한 번의 구조화 응답으로 계획과 문안을 함께 반환합니다. 별도 계획 승인 단계나 자율 에이전트는 없습니다.

### 응답 캐시와 API 스키마

검증을 통과한 AI 출력만 `DATA_DIR/cache`에 저장합니다. 원문·제목·원래 부제·발행 시점·방향·장수·범위·추가 지시·잠긴 값·부분 생성의 비대상 문안·모델·프롬프트/스키마 버전·모의 모드를 SHA-256 키에 반영합니다. 동일 요청은 서버에서 재검증 후 재사용하고 `generation.cached`로 구분합니다. 프로필과 AI가 갱신할 대상 문구는 캐시 키에서 제외합니다. 손상/검증 실패 캐시는 재사용하지 않으며 해당 입력은 다시 생성합니다.

2026-09-17 공식 Structured Outputs 문서의 지원 속성 목록을 확인했습니다. H2는 실제 호출 실패가 확인된 결함이 아닌 미검증 호환 위험입니다. 전송용 JSON Schema에서는 문자열 `minLength`/`maxLength`를 제외하고, SDK 파서 및 서버의 전체 Zod 검증에서는 기존 길이·근거 제한을 그대로 적용합니다. 모델은 `gpt-6-astra`로 유지했습니다. 실제 유료 호출 검증은 하지 않았습니다.

## 공용 계정 로그인

`AUTH_FILE`에 `{ "username": "공용 아이디", "passwordHash": "bcrypt 해시" }` 형식의 서버 전용 JSON 경로를 지정합니다. 또는 `AUTH_USERNAME`과 `AUTH_PASSWORD_HASH`를 설정합니다. 계정 미설정 시 일반 실행은 로그인을 허용하지 않습니다. `MOCK_AI=1`이고 계정 미설정인 테스트 서버만 인증을 생략합니다. 운영 환경에서는 `MOCK_AI`를 설정하지 않습니다.

로그인 세션은 HttpOnly/SameSite 쿠키로 12시간 유지되며, 운영 HTTPS에서는 Secure가 적용됩니다. 서버 재시작 시 재로그인이 필요합니다. 새로고침 시 현재 탭의 작업을 복원합니다. 배포 스크립트는 기존 Caddy 공용 계정 해시를 서버 전용 파일로 이전하고, 앱의 인증 설정 확인 후 브라우저 기본 인증창을 제거합니다.

## AI 의미 단위 자동 줄바꿈

자동 제목의 표지 렌더 시 기존 `gpt-6-astra`에 제목만 전달해 문장·절·구 단위 후보(최대 3줄)를 받습니다. 원문의 연속된 부분 문자열만 허용하며 숫자·따옴표·슬래시·단어·어순을 바꾼 응답은 거부합니다. 의미상 우선 후보를 88/80/72px의 실제 폰트로 측정해 선택합니다. 같은 제목과 프롬프트는 검증된 응답 캐시를 재사용하며, 동시 요청은 합칩니다. 원문 기사·사진은 이 요청에 포함하지 않습니다.

수동 줄바꿈(`/` 또는 줄바꿈)이 있거나 본문 페이지만 렌더할 때는 이 API를 호출하지 않습니다. AI 실패 또는 폭 초과 시 예전 규칙으로 몰래 대체하지 않고 오류를 표시합니다. 기존 원문과 결과는 유지되며 재시도 또는 수동 줄바꿈이 가능합니다. `MOCK_AI=1`의 로컬 테스트만 기존 결정적 분할을 사용합니다. 이전에 저장된 PNG는 다시 렌더해야 적용됩니다.
